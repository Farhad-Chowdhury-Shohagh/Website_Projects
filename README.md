# Website Projects

## 📌 Overview

This repository contains a responsive and interactive websites developed using **HTML**, **CSS**, and **JavaScript**. The project focuses on creating a clean, modern, and user-friendly web interface with proper layout design, styling, and basic interactivity.

Those websites are designed to demonstrate fundamental front-end web development skills, including webpage structure, responsive design, styling, and client-side scripting.

---

## 🚀 Features

- Responsive website layout
- Clean and modern user interface
- Interactive elements using JavaScript
- Organized HTML, CSS, and JavaScript files
- Easy-to-understand code structure
- Mobile-friendly design
- Beginner-friendly front-end project
- Suitable for academic or portfolio purposes

---

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the website
- **CSS3** – For designing and styling the webpage
- **JavaScript** – For adding interactivity and dynamic behavior
